# DataLineage AI — real email setup (Milestone 22)

The application already supports one-time email verification, resend verification, password reset, and organization invitations. Milestone 22 improves the SMTP delivery format and configuration validation. Real delivery is configured on the backend only.

## 1. Keep local development working

For local development, keep the settings generated by `setup-local.ps1`:

```dotenv
DATALINEAGE_ENVIRONMENT=development
DATALINEAGE_EMAIL_DEV_MODE=true
```

In this mode the API returns a one-time development link. No SMTP connection is made.

## 2. Configure real SMTP delivery

To send real messages, edit `backend/.env` and set the following values. Example values below use Gmail SMTP; use your provider's documented host and port if you use another provider.

```dotenv
DATALINEAGE_ENVIRONMENT=development
DATALINEAGE_EMAIL_DEV_MODE=false
DATALINEAGE_PUBLIC_BASE_URL=http://127.0.0.1:8000
DATALINEAGE_SMTP_HOST=smtp.gmail.com
DATALINEAGE_SMTP_PORT=587
DATALINEAGE_SMTP_USERNAME=your-sending-address@gmail.com
DATALINEAGE_SMTP_PASSWORD=your-provider-app-password
DATALINEAGE_SMTP_FROM_EMAIL=your-sending-address@gmail.com
DATALINEAGE_SMTP_STARTTLS=true
DATALINEAGE_SMTP_SSL=false
```

For Gmail, use an App Password where supported; do not put your normal account password in this file. Protect `backend/.env`, never commit it, and never paste it into chat or screenshots.

For providers using implicit TLS (commonly port 465), use:

```dotenv
DATALINEAGE_SMTP_PORT=465
DATALINEAGE_SMTP_STARTTLS=false
DATALINEAGE_SMTP_SSL=true
```

Do not enable both SSL and STARTTLS. If SMTP authentication is required, set both username and password; otherwise leave both blank only when your provider explicitly supports unauthenticated relay.

## 3. Restart and test

From the project root, open the backend:

```powershell
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Register using an email inbox you can access. The API sends a verification message. If the account was already created but remains unverified, use **Resend verification email** on the sign-in screen. Test password reset as well.

If delivery fails, check the backend terminal and the SMTP host, port, authentication, sender address, and encryption mode. The API intentionally does not reveal whether an email address belongs to an account during resend or password-reset requests.

## 4. Production requirements

Before production, set `DATALINEAGE_ENVIRONMENT=production`, use an HTTPS `DATALINEAGE_PUBLIC_BASE_URL`, set `DATALINEAGE_SECURE_COOKIE=true`, use explicit HTTPS CORS origins, and configure real SMTP. Never enable development email mode in production. Configure SPF, DKIM and DMARC for the sending domain to improve deliverability. Test delivery with a mailbox at more than one provider before inviting customers.
